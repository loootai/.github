# loootai/.github

The organisation profile shown on https://github.com/loootai (`profile/README.md`) and shared images.

- `profile/banner.png`: 1600x560 banner for the profile.

The banner background was generated with Gemini 3 Pro Image; the wordmark and text are the real brand assets laid over it.
